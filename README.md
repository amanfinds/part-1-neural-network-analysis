Neural Network Fundamentals and Training Behavior Analysis
Objective

The goal of this project is to build and analyze a feed-forward neural network for customer churn prediction.

Dataset

Dataset used:

customer_churn_nn.csv

Target variable:

churn (1 = churned, 0 = retained)
Tasks Performed
Dataset exploration
Missing value handling
Feature encoding
Feature scaling
Neural network model building
Model evaluation
Hyperparameter experimentation
Technologies Used
Python
TensorFlow / Keras
Pandas
Scikit-learn
Matplotlib
Seaborn
Model Performance

The neural network achieved good classification performance for customer churn prediction and different hyperparameter configurations were compared.
